# Security Policy

## Reporting a vulnerability

Report suspected security vulnerabilities privately to
[security@astoncyber.com](mailto:security@astoncyber.com). Do not report a
suspected vulnerability through a public GitHub issue.

Include a concise description, the affected location, and clear reproduction
details where practical. Do not include credentials, regulated data, or other
sensitive information unless Aston Cyber has provided an appropriate method
for doing so.

The complete reporting guidance is available on the
[Responsible Disclosure page](https://astoncyber.com/disclosures/).

## Responsible handling

Avoid accessing, modifying, retaining, or disclosing data beyond what is
necessary to demonstrate an issue. This policy does not grant authorization to
test any system. Obtain authorization before testing systems you do not own,
including third-party systems.

Receipt will be acknowledged when operationally possible. Aston Cyber does not
guarantee a response or remediation deadline, offer a bug bounty, or make a
safe-harbor commitment through this policy.
